# Telegram Deep Links

ArtFlowWeb формирует ссылку на конкурс в формате:

`https://t.me/{BOT_USERNAME}?start=competition_{id}`

Telegram передаёт боту команду:

`/start competition_{id}`

Бот строго проверяет payload `competition_{id}`: ID должен быть положительным
целым числом без дополнительных аргументов или суффиксов.

После разбора ID бот проверяет конкурс в PostgreSQL:

- конкурс должен существовать;
- веб-данные конкурса должны существовать;
- `is_published` должен быть `True`.

Если ссылка некорректна, конкурс удалён или не опубликован, пользователь
получает обычное главное меню без технических ошибок.

Для корректной ссылки бот сохраняет выбранный конкурс:

`user_data[chat_id]["selected_competition"] = "competition_{id}"`

Дальше работает существующий сценарий регистрации. При подтверждении заявки
он записывает `competition_id` и `competition_name` в `ArtFlow_bid`.
